# おひつじ ポートフォリオ

おひつじのポートフォリオサイトです。

## 構成

- HTML
- CSS
- JavaScript（フッターの年表示のみ）
- Vercel（ホスティング）

フレームワーク、CSSライブラリ、パッケージマネージャー、ビルド処理は使用していません。

## ページ

- `/` — トップページ
- `/privacy/` — プライバシーポリシー

## ローカル確認

任意の静的ファイルサーバーで、このディレクトリを公開します。

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。
